PS-05 — Tracing the Signal

Incident Update

A network capture was recorded during the Project Shadow breach. Most of the traffic appears normal, but investigators believe the attacker communicated with an external command-and-control service.

Analyse the network traffic, identify suspicious communication, and recover the evidence transferred during the breach.

Objectives

  • Analyse the supplied network capture.
  • Identify suspicious or abnormal traffic.
  • Locate the command-and-control communication.
  • Reconstruct the Stage 5 flag from network evidence.
  • Recover transferred artefacts required for the next stage.

Evidence

Download shadow_breach_capture.pcap

Evidence Type: Network packet capture (.pcap)

Recommended Tools

  • Wireshark
  • tshark
  • NetworkMiner
  • binwalk
  • foremost

Progressive Hints

Hint 1:

Regular traffic doesn't usually beacon at fixed intervals.


Hint 2:

Follow the stream — the file didn't just disappear after the transfer.

Flag Format

SHADOW{lowercase_words_with_underscores}
