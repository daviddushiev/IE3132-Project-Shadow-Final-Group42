PS-04 — Recovering the Evidence

Incident Update

IT has obtained a forensic image of a Solace Dynamics file server that was accessed during the breach.

The attacker attempted to remove evidence before leaving the system. Determine what was deleted and recover the remaining evidence.

Objectives

  • Examine the provided forensic disk image.
  • Identify deleted evidence.
  • Recover the deleted archive.
  • Extract and examine its contents.
  • Recover the Stage 4 flag.
  • Identify information required for the next stage.

Evidence

Download evidence.dd

Evidence Type: Raw forensic disk image (.dd)

Recommended Tools

  • Autopsy / Sleuth Kit
  • fls
  • icat
  • tsk_recover
  • strings
  • Hex editor

Progressive Hints

Hint 1:

Deletion doesn't erase — it just forgets the pointer.


Hint 2:

Check the access logs for anything that isn't a normal file operation.

Flag Format

SHADOW{lowercase_words_with_underscores}
