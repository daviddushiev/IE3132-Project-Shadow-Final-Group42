PS-06 — The Attacker's Tool

Incident Update

The executable recovered from the network capture appears to be the tool used by the attacker to package and protect the stolen Project Shadow research data.

Reverse engineer the executable, determine how it protects the data, and recover the missing research.

Objectives

  • Analyse the supplied Linux executable.
  • Identify the embedded secret or key.
  • Understand the transformation logic.
  • Reproduce the logic using a script.
  • Decrypt the stolen research data.
  • Recover the Stage 6 flag.

Challenge Files

Download attacker_tool Download stolen_data.enc

Recommended Tools

  • Ghidra
  • strings
  • objdump
  • gdb
  • Python

Progressive Hints

Hint 1:

The key doesn't have to be guessed if it's sitting in the binary itself.


Hint 2:

Static analysis will get you further than trying to run it blind.
