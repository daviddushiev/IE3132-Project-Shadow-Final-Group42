PS-07 — The Backdoor Account

Incident Update

The stolen Project Shadow research has been recovered. However, the investigation has uncovered another threat.

The attacker created a persistent backdoor account on a Solace Dynamics Linux staging server to maintain unauthorized access.

Investigate the compromised server, identify the security misconfiguration, and recover the final evidence to close the incident.

Objectives

  • Connect to the Linux staging server using SSH.
  • Identify the current user and system privileges.
  • Enumerate sudo permissions and system configuration.
  • Discover the privilege-escalation vulnerability.
  • Obtain root privileges.
  • Recover the final flag from /root/flag.txt.
